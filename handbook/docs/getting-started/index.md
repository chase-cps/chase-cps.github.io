# Getting started

- [Installation](install.md): the Python package (`pip install chase-cps`),
  the solvers it uses (`chase-cps install nuxmv --accept-license`,
  `chase-cps install slugs`), the Docker image with all the tools and the
  demos, or the sources.
- [A first contract](first-contract.md): write a system contract and two
  component contracts, compose the components, check that they refine the
  system, read a counterexample, and find the requirements in conflict.

Then the [demos](../demos/index.md) follow design problems from start to end,
and [Contract theory](../contracts/index.md) explains the operations.
